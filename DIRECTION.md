# Contribution workspace

## Scope

Operate mode. Help a contributor resume work, capture review feedback, and identify the next action across repositories. This records the implemented direction, not a retrospective claim of user-approved design options.

## Form

A contribution workbench with a midnight navy navigation rail, cool silver working surface, violet activity panel, chrome Git branch sculpture, and a restrained lilac accent. The user supplied eighteen style references and explicitly chose a blend of selected styles rather than eighteen switchable themes. The implementation combines Bauhaus and De Stijl geometry, tactile skeuomorphic controls, an inflated blue tile, a liquid-chrome disc, and restrained Memphis playfulness. Task content remains calm and readable. This is the user-pinned blend, implemented directly in code; there is no image comp or external quality-card comparison. The engine limitation from the initial build remains documented rather than fabricated as direction-roll evidence.

## First viewport

Show the two-line contribution workbench heading, GitHub sync action, active/review/completed counts, requested-change follow-up, and searchable table. Syne carries headings and metrics. DM Sans carries controls and records. Chrome geometry is confined to the logo and header sculpture. All contributions are live public GitHub records.

## Signature interaction

Select a title or next action to view GitHub source fields and edit local workflow notes. GitHub statuses are read only. The detail panel slides in over 220 milliseconds and respects reduced motion. All-fields mode makes the same stored details visible as additional table columns. The violet sync action has tactile hover and press feedback. Header artwork is static and ignores pointer events.

## Responsive behavior

On phones, reduce navigation to an accessible icon rail, stack dashboard totals, and contain horizontal scrolling inside the table and filter tabs. Keep the page itself at viewport width. Protect the edit task in a native dialog with form labels and keyboard cancellation.
